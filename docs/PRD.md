# PRD — Mosaic Unified Wellness Companion (MERN)

## 1. Problem
4 siloed brands (Bodywise, Little Joys, Man Matters, Root Labs). Relationship is transactional: buy → use → maybe repurchase. Reviews <1%, Day-30 drop, zero cross-brand (0/11 surveyed tried sibling), consult unused.

## 2. Objective
Consumer is hero, product is supporting cast. Return reason: understand self, build habits, track journey, discover relevant solutions. Wellness first, commerce second.

## 3. Loop
CHECK IN → DNA → HABITS → CALENDAR/SHELF → INSIGHTS → COMPLETE → REWARD (trial) → DISCOVER → NEW HABIT.
Brand gate first (4 brands), no catalogue push.

## 4. Scope v1 (per brief §§3-14)
- Brand gate; 10-area emoji check-in; dynamic Wellness DNA (Sleep|Mood|Energy|Nutrition|Skin|Hair|Activity|Stress|Hydration, dots not medical scores).
- Calendar: moods, check-ins, delivery/finish/restock/review/milestones.
- Shelf: name/brand/image/purchase/usage/days-left/finish/progress/restock; auto-add on purchase.
- Smart restock by official usage (not blanket 30d): Ready to restock? RESTOCK/PASS + why (results/liked/routine/concern/reco vs no-result/dislike/price/forgot/need/switch/other).
- Honest Reviews (liked/disliked/expectations) verified-only; Honest SKU Check (details/ingredients/usage/duration/precautions/authenticity/reviews).
- AI Friend floating bottom-corner, wellness-only, non-intrusive, no diagnosis.
- Family Circle (parent/partner/sibling/child), simple, cross-brand surface.
- Habit rewards: 30-day unlock → other-brand trial (e.g. Bodywise → Little Joys/Man Matters/Root Labs).

## 5. Metrics
Return rate, check-in streak, habit completion, restock + reason rate, review rate, trial claim → adoption, cross-brand discovery.
